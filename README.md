# Amazon Product Scraper

## Overview
This project is a Python-based web scraping tool developed during my internship to collect structured product data from Amazon Best-Seller pages for business analytics and reporting.

The scraper extracts key product information such as:
- Product name
- Category ranking
- Price
- Ratings
- Product links

The collected data is exported into CSV and Excel formats for further analysis and visualization.

## Tools & Technologies
- Python
- Selenium
- BeautifulSoup
- Pandas
- Excel / CSV

## Project Structure
- Individual Python scripts for different product categories
- A centralized script (`run_all.py`) to execute all scrapers together
- Output datasets stored in CSV and Excel formats

## Use Case
The project supports market analysis, competitor benchmarking, and trend identification by automating large-scale data collection from e-commerce platforms.

## Note
This repository contains the project code and sample outputs. Browser drivers are excluded as per best practices.
